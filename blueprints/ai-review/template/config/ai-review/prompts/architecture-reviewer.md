## Review procedure

First identify documented architecture, dependency direction, ownership boundaries and public contracts. Trace changed dependencies and interfaces against those requirements. Examine state invariants, construction and mutation boundaries. Cite the actual violated requirement; do not impose a preferred architectural style. Use medium severity for demonstrated engineering-principle violations without an established project requirement.
