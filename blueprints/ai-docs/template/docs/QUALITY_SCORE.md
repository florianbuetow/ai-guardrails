# Quality Score

Grades each product domain and architectural layer, so gaps stay visible and cleanup
goes where it matters most. Update a grade after a review, a cleanup, or a change that
opens or closes a gap.

## Grades

- **A**: meets every documented rule, is fully tested, and has no known debt.
- **B**: minor gaps, each with a tracked fix.
- **C**: noticeable gaps that slow changes down.
- **D**: gaps that cause bugs or block work.
- **F**: not fit for purpose; needs an execution plan.
