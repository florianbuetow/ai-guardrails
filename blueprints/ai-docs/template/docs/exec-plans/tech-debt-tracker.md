# Tech Debt Tracker

Known technical debt that is not being fixed right now. Recording it keeps the debt
visible, so it gets paid down in small steps instead of being rediscovered.

Add a row when you find debt you will not fix in the current change. Delete the row in
the commit that pays the debt down. Link the execution plan or design doc when one
exists.
