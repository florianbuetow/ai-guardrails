# Generated Documents

Documents in this folder are produced by tools from a source of truth, for example a
database schema dump (`db-schema.md`) or an API reference. They give agents exact,
current facts without reading the underlying code.

Never edit a generated document by hand: change its source and regenerate it. Start
every generated file with a line naming the command that produced it, and list it
below.
