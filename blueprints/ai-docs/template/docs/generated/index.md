# Generated Documents

This index lists the documents in this folder that tools generate from a source of
truth, such as a database schema (`db-schema.md`) or an API reference. Generated
documents give agents exact, current facts without reading the underlying code.

- Never edit a generated document by hand. Change its source, then regenerate it with
  the command listed below.
- Start every generated document with a line naming the command that produced it.
- This index is the only hand-written file in the folder. Add a row when you add a
  generated document, and remove the row when you remove one.
